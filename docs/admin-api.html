Admin API

Create a key in Admin → Integrations. Every key has full read and write access and can work in any project.

Base URL: https://unified.nexuses.xyz. The full key is shown only once, as up_live_….

Authentication

Send the key on every portal request, and name the project with X-Project-Id (project id or slug).

Authorization: Bearer up_live_…
X-Project-Id: PROJECT_ID

Missing X-Project-Id returns 400. An unknown project returns 404. A revoked or wrong key returns 401.

Projects

GET /api/projects returns every project. Use id as X-Project-Id.

curl https://unified.nexuses.xyz/api/projects

Senders

All sender calls use the two headers above. Secrets in responses are masked.

Add an AWS SES sender

curl -X POST https://unified.nexuses.xyz/api/smtp/senders \
  -H "Authorization: Bearer up_live_…" \
  -H "X-Project-Id: PROJECT_ID" \
  -H "Content-Type: application/json" \
  -d '{
    "provider": "aws_ses",
    "fromEmail": "you@company.com",
    "smtpHost": "email-smtp.us-east-1.amazonaws.com",
    "smtpUser": "SMTP_USER",
    "smtpPassword": "SMTP_PASSWORD",
    "smtpPort": 587,
    "noInbox": true
  }'

201 returns the sender, including id. A duplicate from-email for the same provider returns 409.

Providers

providerRequired fields
aws_sessmtpHost, smtpUser, smtpPassword, smtpPort, fromEmail
gmailSame SMTP fields. Optional dailyLimit (1–140, default 80).
outlookSame SMTP fields. Host default smtp-mail.outlook.com, port 587.
sendgridapiKey, fromEmail
resendapiKey, fromEmail
cloudflarecloudflareAccountId, cloudflareEmailApiToken, fromEmail

Optional on every provider: noInbox (true skips SPF, DKIM, and DMARC checks).

Update

Send the same fields. Password and API-key fields can be omitted to keep the stored secret.

curl -X PATCH https://unified.nexuses.xyz/api/smtp/senders/SENDER_ID \
  -H "Authorization: Bearer up_live_…" \
  -H "X-Project-Id: PROJECT_ID" \
  -H "Content-Type: application/json" \
  -d '{ "fromEmail": "new@company.com", "smtpHost": "email-smtp.us-east-1.amazonaws.com", "smtpUser": "SMTP_USER", "smtpPort": 587 }'

Delete

curl -X DELETE https://unified.nexuses.xyz/api/smtp/senders/SENDER_ID \
  -H "Authorization: Bearer up_live_…" \
  -H "X-Project-Id: PROJECT_ID"

Success: { "success": true }.

Other portal APIs

The same Authorization and X-Project-Id headers work on the project’s portal APIs (CRM, campaigns, inbox, analytics). The key is not limited to senders.

Managing keys

Key create, list, and revoke stay in the admin console (Admin → Integrations). They use the admin login, not the API key.
